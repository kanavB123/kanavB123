## 👋 About Me

I’m a university student working at the intersection of Machine Learning, Deep Learning, and Full-Stack software development. I’m driven by the idea of building intelligent systems that are not only accurate, but also explainable, practical, and deployment-ready.

### 🔬 Research & Focus Areas
- Deep learning for time-series forecasting using LSTM, BiLSTM, and CNN-LSTM models
- Explainable AI with LIME and model interpretability methods
- Deep learning for protein-protein interaction prediction
- Problem-based learning (PBL) projects rooted in real-world AI applications
- Full-stack AI product development with backend APIs and user-facing interfaces

### 💼 Development Experience
- REST APIs with Node.js and Express.js
- SQLite-backed application architecture
- End-to-end AI web applications with both frontend and backend integration
- Model experimentation, evaluation, and deployment workflows
